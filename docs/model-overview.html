Step 2 · What a move is worth

One currency: win-pts, percentage points of a weekly win

1 win-pt = 0.01 expected weekly wins, summed over every week a move touches. Today's plan, +11, is 0.11 more weekly wins expected this season; an add must buy 10 (0.1 wins) to be worth one of the 33 left.

value = Δ P(win) this week + Δ P(win) in weeks +1, +2 (against the real opponents) + later points × a point's worth

Step 3 · The rule

From a ranked table to one plan you can follow

1

Worth an add?

An add costs what it could buy later. The add price (10 win-pts today) is set by simulating weeks so that 2 a week at most uses the budget at its pace, 6 kept for the playoffs. Close weeks with good streamers clear it; lopsided weeks don't.

2

One coherent plan

Best move first, each next one judged with the earlier ones made: no two share a player. A keeper that does nothing this week waits for Monday only if another move can use this week's add, else it takes the add that would expire.

3

The exact day

The earliest day that loses no points: the dropped player's games first, the add in before his. Waiting otherwise only risks a claim. IR: an add into a spot IR opened counts only until the injured player is back.

4

Kept once seen

The plan changes only if a move can't be made (taken, skipped, injured) or a new plan is 2 win-pts better, and says why. Week 2 had 13 cards with 4 different adds; now near-ties don't flip it.

9.7 → 10

win-pts an add must buy

A point is worth most when a matchup is close: about 0.9 win-pts in a typical week, far less in a lopsided one. So the same +5-point stream can be a must-add in a 50% week and worthless at 90%: the rule follows from the numbers, not from a fixed "stream on Mondays".
